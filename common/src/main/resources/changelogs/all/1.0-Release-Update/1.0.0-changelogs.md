## Version Release v1.0.0 MC-1.20.1

### Additions
- Added Coral Dye, this can be created with Red Dye, Orange Dye, and White Dye or Peach Bellflowers (which generate in Savannas)
- Added Canary Dye, this can be created with Yellow Dye and White Dye or Goob Blossoms (which generate in Swamps)
- Added Wasabi Dye, this can be created with Lime Dye and White Dye
- Added Sacramento Dye, this can be created with Green Dye and Cyan Dye or Glow Ink Sacs
- Added Sky Dye, this can be created with Light Blue Dye and White Dye
- Added Blurple Dye, this can be created with Blue Dye and Purple Dye or Blueberries (which generate in Forests)
- Added Sangria Dye, this can be created with Purple Dye and Magenta Dye or Sweetberries
- Added Rose Dye, this can be created with Pink Dye and Red Dye or Roses (which generate in Forests)

### Notes
- Currently, there are no Llama carpet textures (these will be added later)
